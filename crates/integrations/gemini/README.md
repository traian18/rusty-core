# harness-integration-gemini

Model backend for the Google Gemini API.

## What's inside

- Integration id: `gemini`.
- `wire`, `client`, `config`, `usage` — Gemini content/part types, the `ModelClient`, configuration and usage accounting.

## In the workspace

- **Depends on:** `harness-generic-backend`, `harness-model`, `harness-protocol`, `harness-runtime`
- **Used by:** `harnessd`
